# Spring AI Budgeting Assistant

API financeira inteligente desenvolvida com Spring Boot e Spring AI.

O projeto processará comandos financeiros em texto ou áudio, identificará a intenção do usuário e executará casos de uso reais por meio de Tool Calling.

## Status

Projeto em desenvolvimento.
